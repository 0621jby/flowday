## 权益和价格假设

拒绝把数据导出、删除、基础安全和手工任务能力做成付费壁垒。用户愿为持续减少执行摩擦付费的假设尚未验证；不要用比竞品低的价格替代产品价值。

| 权益 | Free | Pro 初始方案 |
|---|---|---|
| 任务、手工计划、执行、基础复盘 | 有，合理滥用限额且透明 | 有 |
| 活跃目标 | 3 | 30（非宣传无限） |
| 规则排程 | 单日 | 14天与高级约束 |
| AI 教练 | 每月10单位 | 每月200单位 |
| AI计费单位 | 普通建议1、深度目标拆解5，操作前标明 | 相同规则 |
| 分析 | 基础周视图 | 历史趋势与证据化画像（上线后才宣传） |
| 数据保留/导出删除 | 可导出全部仍保留的数据 | 同样支持 |
| 价格 | $0 | 初始测试$9/月、$90/年；另测$8与$12，非最终售价 |

首轮封闭测试先免费验证闭环；公开收费前实现完整取消、失败续费、退款处理和客服入口。年付只在真实留存成立后推广。MVP 不售额外额度包，避免多重账本和退款复杂度。

## 额度和订阅状态

用户看到的是动作单位，不把 token 计价细节强加给用户。每个动作有输入输出上限，失败不重复扣用户单位；供应商失败发生的真实成本仍入成本账。请求前在事务中锁 usage_period 行并预占，余额不足立即拒绝模型调用；成功 settle、失败 release。崩溃后靠幂等 run ID 对账释放；不能单凭超时释放仍在运行的请求。

额度期使用订阅计费 period，Free 使用 UTC 自然月；界面显示当地时间的具体重置时刻。额度不结转，升级按明确规则补差，不通过取消再订阅重置。退款不产生负数无限抵扣。并发请求只能在预占成功后开始。

订阅状态：incomplete → active/trialing → past_due → active 或 unpaid/canceled；cancel_at_period_end 是独立标志，不是即时失效。建议失败续费宽限3天，期末回到Free；数据不删除，超额目标只限制新建/高级编辑。支付提供方状态映射到服务端权益，不信任前端 plan_code。

结账：服务器从白名单 price ID 建 session → 托管支付 → 回调页显示“确认中” → 验签 webhook 入库 → worker 获取提供方最新对象 → 幂等更新订阅与权益 → 通知。事件可能乱序，不能按收到顺序覆盖；每日按 provider 重新核对活跃订阅。取消：清楚展示生效时间 → 提供方确认 → 保留权益至期末；恢复订阅按提供方结果处理。退款/争议/撤销均写独立支付记录，不直接删账。

支付方案：经营主体可用时优先托管支付+客户门户；可比较 Stripe 与 Merchant of Record，后者税务处理便利但费率较高。大陆主体和大陆用户需重新评估本地支付、开票、部署及模型，不假设 Stripe 可直接开通。法务适用性在市场确认后核验，不在此作法律结论。

## 可复算成本模型（USD，预算假设，不是供应商报价）

假设一次普通请求6000输入token、1000输出token；预算单价输入$0.50/百万、输出$2/百万。单次 `6000×0.5/1e6 + 1000×2/1e6 = $0.005`；加重试、摘要等30%余量为$0.0065。深度拆解按5单位约束，不能消费1单位却允许无限链路。实施时替换成选定供应商官方模型单价，模型还未选定，故不伪称实时价格。

样例：1000 MAU，950 Free、50 Pro，Free平均3单位/月，Pro平均80单位/月：总6850单位，模型成本约$44.53/月；全额使用为19500单位、约$126.75。若输入输出单价翻5倍，则典型AI成本约$222.63，必须触发预算警报与模型路由调整。

| 成本项 | 月预算假设 | 说明 |
|---|---:|---|
| 数据库/Auth/存储 | $25–60 | 按实际项目、计算、备份与流量计费，恢复能力另核价 |
| Web部署/CDN | $20–50 | 团队席位、函数、流量超额另计 |
| Worker/队列 | $5–20 | 同仓常驻进程，PG队列不另设Redis |
| 邮件/通知 | $0–15 | 早期少量事务邮件；Web Push仍有开发运维成本 |
| 监控/备份/域名摊销 | $10–30 | 不含人工；PITR可能使预算显著上升 |
| 固定合计 | $60–175 | 作为预算区间，不能据此承诺账单 |

参考核价入口：[Supabase](https://supabase.com/pricing)、[Vercel](https://vercel.com/pricing)。公开定价变动和实际区域、席位、用量会改变成本。

支付手续费暂以 `3% + $0.30/笔` 做敏感性假设，**不是特定国家或提供方实际费率**。50名月付用户收入$450，手续费$28.50；典型模型$44.53，固定成本$60–175，现金贡献约$201.97–316.97，未计税、退款、人工、客服、获客和坏账。年付收入需按月摊销，不能把预收现金全当当月收益。

按Pro平均80单位，单付费用户模型$0.52，支付$0.57，边际贡献约$7.91；若950 Free的模型补贴约$18.53，则覆盖固定成本需要约10–25名Pro（忽略规模变化、人工和税）。这个数字不是商业盈亏平衡；加入人工后需重新测算。免费用户无转化但持续增长会吞掉预算。

## 成本控制与滥用

按用户、动作、模型、Prompt版本采集 token/真实成本、单位预占、失败率和延迟。项目日/月成本在50/80/100%阈值告警；达到硬预算停止非必要模型调用并提供规则替代，不能阻断已付费基础任务访问。外部账单需每日对账，内部估算不是最终费用。

邮箱验证、IP/账号分层速率、风险触发验证码、并发上限2、工具轮次上限、输入长度限制；避免靠简单设备指纹侵入隐私。相同请求幂等，公共缓存不得混入私人上下文。冻结可疑AI能力时保留申诉和手工任务访问。付费计划不能宣传无限AI。
