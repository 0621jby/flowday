# 复盘与交互调整 · 2026-11-19

## 已处理的反馈

1. **拉伸后跳到底部**：resize handle的pointerup后会合成click，原click打开编辑器并触发scrollIntoView。现在手柄的指针点击不打开编辑区；键盘激活（detail=0）仍可打开。直接点击任务正文仍保留精确编辑能力。
2. **30天洞察**：支持7/30天切换，含今天、补零、当地日期聚合。30根柱采用横向滚动而非在手机上挤成细线；可点按查看具体日期和数量。统计口径仍为当前已完成任务，删除/重开任务可能改变历史图表，不伪称不可变成果账本。
3. **涂鸦复盘**：可选开启，五种颜色、三档笔宽、笔画撤销与可撤销清空。SVG向量笔画持久化，不存放任意SVG字符串、不加载外部图片。支持鼠标/触笔/触摸绘画，文字表单仍为完整替代路径。
4. **历史回看**：日期选择、前后一天、回到今天、全部历史记录列表。可补写或编辑过去日期，不写未来日期。文字、心情、涂鸦统一通过“保存复盘”提交。

## 数据安全与范围

- schemaVersion仍为1，reviews新增可选drawing；旧记录可直接读取。JSON导出自动包含涂鸦。
- 每日最多40笔，每笔最多200个点；长笔画逐步抽稀保留走势。坐标、颜色和笔宽有结构化白名单校验，避免无限增长与注入。
- 草稿切换日期前提示保存/放弃/继续；切换应用导航时草稿组件仍挂载；刷新/关闭前有浏览器未保存提醒。未保存草稿不承诺跨关闭恢复。
- 保存前比较当前该日期的记录与编辑基线，避免覆盖其他标签页的复盘更改。localStorage写失败时保留编辑中的草稿，不能显示保存成功。
- 历史记录没有按日清理逻辑。**当前只在这个浏览器中保存**，浏览器清理、换设备或存储故障不提供云端恢复保证。设置中的数据导出可用于备份；当前没有导入入口。
- 贴纸本轮不添加占位素材。用户提供素材后，再设计有限贴纸选择/位置数据；不提前引入完整绘图编辑器。
